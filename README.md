# Virus VS Vaccine landing page

This folder is a static landing page for **Virus VS Vaccine**, a game created by **Kimmy Sha**. The Play buttons open <https://kimmyshakk.itch.io/virus-vs-vaccine>.

## GitHub Pages

Extract the zip and place its contents at the root of a GitHub Pages repository, or in a `/docs` folder configured as the Pages source. Keep `index.html`, `styles.css`, and `assets/` together. No build step is required.

The page can also be previewed locally by opening `index.html` in a browser. Google Fonts are optional; system font fallbacks are included.
